# Machine Learning Project

This repository contains a machine learning classification project implemented in a single Jupyter notebook.
chosen dataset link: https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success
Further explained in *students_notebook.ipynb*.

## Files
- `students_notebook.ipynb`: Complete notebook including data preprocessing, modeling, evaluation, visualizations, and justifications.
- `requirements.txt`: List of required Python libraries.

## How to Run
1. Install dependencies:  pip install -r requirements.txt
2. Open the notebook: jupyter notebook students_notebook.ipynb
3. Run all cells in order.
